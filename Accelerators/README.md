# India Accelerators Master Directory

This directory contains the verified, deduplicated database of **685 pure Accelerator programs** operating in India.

## Definition (Accelerators)
Fixed-term, cohort-based programs (typically **3 to 6 months**) designed to rapidly scale early-to-growth-stage startups that already possess an MVP or early revenue traction. They provide intensive mentorship, investor demo days, corporate pilot access, and upfront seed/pre-seed capital or convertible notes.

## Included Hubs
- **Flagship Top-Tier Institutional & VC Accelerators:** Peak XV Surge, Accel Atoms, 100X.VC, Antler India, Google for Startups Accelerator India, Microsoft Pegasus, T-Hub (Lab32 & T-Angel), CIIE.CO / IIMA Ventures, SINE Accelerate, NSRCEL Velocity.
- **Corporate Accelerators:** Bosch DNA, Brigade REAP, Amazon Propel & Smbhav, etc.
- **Venture Builders & Studio Accelerators:** Favcy, Marwari Catalysts, India Accelerator, etc.
- **MeitY & State Technology Accelerators:** MeitY Startup Hub specialized cohorts.

## Files
- `india_accelerators_master.xlsx` — Excel formatted master file.
- `india_accelerators_master.csv` — UTF-8 CSV data export.

## Schema
1. `name`: Accelerator Program / Entity Name
2. `category`: Accelerator
3. `type`: VC-backed, Corporate, Private, Govt-backed, Academic
4. `city`: City / Base location
5. `state`: State / UT
6. `location`: Normalized Location string
7. `sector_or_stage`: Focus sectors, technology domains, or cohort stages
8. `description`: Program summary and scale-up focus
9. `website`: Official URL
10. `email`: Contact email (where available)
11. `source_authority`: Primary certifying registry
12. `source_url`: Reference source URL
