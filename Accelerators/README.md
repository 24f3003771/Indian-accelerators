# India Accelerators Master Directory (Deep Enriched)

This directory contains the comprehensively crawled and enriched database of **685 pure Accelerator programs** operating across India.

## Schema (28 Standardized Attributes)

| # | Column Name | Type | Description |
|---|---|---|---|
| 1 | **S.No** | Integer | Index serial number (1 to 685) |
| 2 | **Name** | String | Official accelerator program / organization name |
| 3 | **Logo URL** | URL | Direct CDN/Storage logo URL |
| 4 | **Description** | Text | Comprehensive program thesis and value proposition |
| 5 | **Country** | String | Primary country (India / Global India) |
| 6 | **State** | String | State / UT location |
| 7 | **City** | String | City / District base |
| 8 | **Full Address** | Text | Detailed street address / campus location |
| 9 | **Pincode** | Integer | 6-digit Indian postal code |
| 10 | **Website** | URL | Official accelerator website |
| 11 | **Contact Person** | String | Managing Partner / Founder / Program Director |
| 12 | **Contact Designation** | String | Leadership title / designation |
| 13 | **Contact Email** | Email | Official contact / application inbox |
| 14 | **Contact Mobile** | String | Phone / helpline contact number |
| 15 | **Date of Establishment** | String | Year or founding date |
| 16 | **Program Duration (months)** | String | Cohort timeline (e.g., 3 to 4 months, 16 weeks) |
| 17 | **No. of Current Incubatees** | String | Active batch size per cohort (e.g., 10 to 30 startups) |
| 18 | **No. of Graduated Incubatees** | String | Total historical alumni / funded portfolio count |
| 19 | **Portfolio Companies** | Text | Key alumni & marquee startups backed |
| 20 | **Industries** | String | Primary industry category |
| 21 | **Sectors** | String | Specific focus sectors |
| 22 | **Industries (Detailed)** | Text | Comprehensive industry taxonomy |
| 23 | **Sectors (Detailed)** | Text | In-depth domain focus verticals |
| 24 | **Stages** | String | Target stages (Pre-seed, Seed, Early Revenue, MVP, Growth) |
| 25 | **Linkedin** | URL | Official LinkedIn company profile |
| 26 | **X** | URL | Official X (Twitter) profile / handle |
| 27 | **Other Social media** | URLs | YouTube, Instagram, WhatsApp channel links |
| 28 | **Extra Information Identified** | Text | Cheque size, equity terms, corporate partners & thesis |

## Files
- `india_accelerators_master.xlsx` — Full 28-field master Excel workbook.
- `india_accelerators_master.csv` — Full 28-field UTF-8 CSV data file.
